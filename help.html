How to use this website?
  • Step - 1: Type the text that you need to store it in the cloud
  • Step - 2: Type the password for the note that you are sharing
  • Step - 3: Click on the Create Note button to create the note.
  • Step - 4: Note down the 8 - digit Note ID that would be needed to access the note.
  • Step - 5: Note down the 8 - digit Revoke ID that would be needed to instantly delete the note.
  • Step - 6: Note down the 8 - digit Update ID that would be needed to update the note
Points to note:
  • Every note has a by default TTL (Time To Live) of 1 year from its time of creation.
  • The note's TTL will be updated to 1 year from the latest access time.
