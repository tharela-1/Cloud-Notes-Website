Welcome to the Cloud Notes website!

Here you can share and store the data in a very safe way.

You can go and access the home page by clicking on the button given here:

You can set the following details as well:
  1. Message to be stored
  2. Password to open the message

By default, the notes created will have a Time To Live (TTL) of 1 year from the time of creation. Whenever it gets accessed correctly using the correct id and the correct password, the TTL gets updated to 1 year from the last accessed time.
Also, if you want to do instant deletion of your note you can go to the Delete Tab in the home Page and enter the required details there. If all the details are correct, then instant deletion of the note will be done.
